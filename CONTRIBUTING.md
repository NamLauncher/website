# Contributing

Contributions to the public NamLauncher website are welcome.

1. Keep changes inside the public static website boundary.
2. Do not add Admin, backend, deployment, database, report, or secret material.
3. Run `node --test contract-tests/*.test.mjs`.
4. Open a pull request that explains the user-visible change and test result.

By contributing, you agree that your contribution is licensed under this
repository's GPL-3.0 license.
