Supported game types

Choose the loader that fits the instance.

NamLauncher keeps the Minecraft version, loader build, Java runtime, and installed files together, so changing one instance does not rewrite another.

VanillaMinecraft without a mod loader
FabricLightweight loader with a large mod ecosystem
ForgeLong-running loader for many established modpacks
NeoForgeModern Forge-family loader for newer releases
QuiltFabric-compatible ecosystem with Quilt tooling

Loader versions are filtered against the selected Minecraft version before installation.

Managed Java runtime

Java is selected from the Minecraft version.

NamLauncher follows Mojang's version metadata first. If that service is temporarily unavailable, it uses this tested fallback map.

Managed runtimes are Eclipse Temurin OpenJDK with the HotSpot JVM, downloaded from the official Eclipse Adoptium API and verified with SHA-256.

Java 8Minecraft 1.16.5 and older
Java 16Minecraft 1.17.x
Java 17Minecraft 1.18–1.20.4
Java 21Minecraft 1.20.5–1.21.11
Java 25Minecraft 26.x and newer

Why NamLauncher

The useful difference is in the whole workflow.

No single checkbox makes a launcher special. NamLauncher connects setup, content, launch, in-game identity, updates, and support around the same instance.

An instance is more than a game version

Its files, mods, worlds, servers, screenshots, logs, Java runtime, memory limit, and playtime stay together.

Modrinth and CurseForge share one screen

Switch the source, compare compatible files, and install into the current instance without rebuilding the setup.

Recognize NamLauncher players in game

Supported companions add the launcher mark to nametags, the tab list, and chat, plus a local /namlauncher player list.

A fair comparison

Different launchers are built for different jobs.

The notes below use each project's own feature pages. They describe focus and workflow, not a winner.

TLauncher

TL MODS and its own modpack flow

TLauncher already supports modpacks, dependency installs, manual files, and backups. NamLauncher differs by making the full instance—Java, memory, worlds, logs, servers, and both public content providers—the center of the app.

Official feature page↗
Modrinth App

A polished home for Modrinth content

Modrinth App manages instances, updates, imports, skins, and Modrinth-hosted projects. NamLauncher adds a CurseForge choice beside Modrinth and keeps its own server, log, Java, and launcher tools in the same instance view.

Official feature page↗
CurseForge App

Deep access to the CurseForge catalog

CurseForge provides profiles, loader filters, mod and modpack installs, and automatic addon updates. NamLauncher keeps CurseForge available while also letting the same instance browse Modrinth.

Official feature page↗
Lunar Client

A bundled client with built-in game mods

Lunar focuses on an all-in-one client, built-in performance and PvP mods, plus custom Fabric mods on supported versions. NamLauncher focuses on ordinary Vanilla, Fabric, Forge, NeoForge, and Quilt instances where you choose the content.

Official feature page↗
Prism Launcher

The closest match for instances and two providers

Prism already manages instances and installs from both Modrinth and CurseForge. NamLauncher's added focus is Thai-first guidance, managed in-game identity, Discord linking, guided troubleshooting, and a launcher update flow designed for its community.

Official feature page↗
ATLauncher

A broad modpack launcher with several catalogs

ATLauncher provides its own modpacks and can browse packs from CurseForge, Modrinth, and Technic. NamLauncher differs through Thai-first guidance, managed Java, in-game identity, Discord linking, and support tools built around its community.

Official feature page↗
