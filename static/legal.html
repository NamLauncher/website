ข้อกำหนดการใช้งาน

1. การยอมรับและคุณสมบัติผู้ใช้

ใช้ NamLauncher เฉพาะเมื่อคุณสามารถยอมรับข้อกำหนดนี้และการประมวลผลที่จำเป็นซึ่งเปิดเผยในประกาศความเป็นส่วนตัวได้ตามกฎหมาย หากกฎหมายกำหนดให้มีผู้ปกครอง ผู้ปกครองต้องอ่านและยอมรับร่วมกับคุณ

2. สิทธิ์ใช้งานส่วนบุคคล

อนุญาตให้ติดตั้งและใช้ NamLauncher รุ่นทางการเพื่อการใช้งานส่วนบุคคลที่ชอบด้วยกฎหมาย การขาย แจกจ่ายแบบมีค่าใช้จ่าย หรือใช้แบรนด์เชิงพาณิชย์ต้องได้รับอนุญาตเป็นลายลักษณ์อักษร โดย license บุคคลที่สามและโอเพนซอร์สยังคงมีผล

3. โปรเจกต์อิสระและกฎของบริการอื่น

NamLauncher เป็นลันเชอร์ชุมชนอิสระและไม่ได้รับรองโดย Mojang, Microsoft, Discord, Modrinth, CurseForge หรือผู้พัฒนา loader ผู้ใช้ต้องปฏิบัติตาม Minecraft EULA, Usage Guidelines, กฎเซิร์ฟเวอร์ และข้อกำหนดของบริการที่เชื่อมต่อ

4. สิทธิ์ Minecraft โปรไฟล์ และการเข้าเซิร์ฟเวอร์

ใช้เฉพาะบัญชีที่เป็นของคุณหรือได้รับอนุญาต โปรไฟล์ Offline หรือ Cracked เป็นเพียงตัวตนในเครื่อง ไม่ได้ให้ใบอนุญาต Minecraft ไม่ข้าม online-mode authentication และไม่อนุญาตให้เข้าเซิร์ฟเวอร์โดยไม่มีความยินยอม

5. การเล่นอย่างเป็นธรรม ตัวตน และบัญชี

ห้ามสวมรอย ขโมยหรือใช้ credential และ token ในทางมิชอบ เลี่ยงแบน ปั่นจำนวนผู้เล่น คุกคาม ฉ้อโกง หรือใช้ cheat, exploit และ automation ที่บริการห้าม

6. ความปลอดภัย ระบบอัตโนมัติ และการใช้งานที่เป็นอันตราย

ห้ามเข้าถึงระบบหรือข้อมูลโดยไม่ได้รับอนุญาต ข้าม authentication, access control, rate limit หรือ security check รบกวนบริการ สร้างบัญชีจำนวนมาก scrape อย่างรุนแรง แจกมัลแวร์ หรือขโมยความลับ

7. การทำวิศวกรรมย้อนกลับและข้อยกเว้นที่ได้รับความคุ้มครอง

ห้าม reverse engineer, decompile, disassemble, decode หรือดึง source code กรรมสิทธิ์ key และ protocol ส่วนตัว เว้นแต่กฎหมายอนุญาต จำเป็นต่อ interoperability ที่ชอบด้วยกฎหมาย เป็นการวิจัยความปลอดภัยโดยสุจริตพร้อม responsible disclosure หรือเป็นสิทธิตาม license โอเพนซอร์ส ข้อยกเว้นไม่อนุญาตให้ทำอันตราย เข้าถึงข้อมูลผู้อื่น หรือแจกมัลแวร์

8. การแจกจ่าย แบรนด์ และรุ่นทางการ

ห้ามขาย แพ็กใหม่ mirror แจก binary หรือแบรนด์ ลบเครดิต แสดงรุ่นดัดแปลงว่าเป็นทางการ หรือทำลิงก์ดาวน์โหลดหลอกลวงโดยไม่มีสิทธิ์ ทั้งนี้ไม่จำกัดสิทธิ์ที่กฎหมายหรือ license โอเพนซอร์สมอบให้

9. ทรัพย์สินทางปัญญาและคอนเทนต์บุคคลที่สาม

NamLauncher และ asset ต้นฉบับเป็นของ nattapat2871 เว้นแต่ระบุอย่างอื่น Minecraft เป็นของ Microsoft หรือ Mojang ส่วน mod, loader, resource pack, skin และ library เป็นของผู้สร้างแต่ละราย โปรดตรวจ license และความปลอดภัยก่อนใช้หรือแชร์

10. ความรับผิดชอบต่ออุปกรณ์ เครือข่าย LAN และข้อมูลสำรอง

รักษาความปลอดภัยของอุปกรณ์ บัญชี world และข้อมูล ใช้ LAN เฉพาะบนเครือข่ายที่ไว้ใจและได้รับความยินยอม สำรองข้อมูลก่อน update, import, ย้ายข้อมูล หรือทดลอง และรับผิดชอบ firewall, server, storage และ bandwidth ของตน

11. การดาวน์โหลด อัปเดต และบริการที่เชื่อมต่อ

ลันเชอร์อาจติดต่อ hosted API และดาวน์โหลด Minecraft, Java, loader, metadata, update และคอนเทนต์ที่เลือก โปรดตรวจแหล่งทางการและ checksum เมื่อมี บริการบุคคลที่สามอาจล่มหรือเปลี่ยนกฎโดยอยู่นอกการควบคุมของ NamLauncher

12. ความพร้อมใช้งาน การบังคับใช้ และการยุติ

ฟีเจอร์ออนไลน์ไม่มีการรับประกัน uptime NamLauncher อาจจำกัด บล็อก หรือยุติการเข้าถึงบริการเมื่อมีการละเมิดกฎ กฎหมาย หรือระบบความปลอดภัย ผู้ใช้ยุติได้ด้วยการหยุดใช้และถอนการติดตั้ง ส่วนการลบข้อมูลในเครื่องต้องทำแยก

13. Community build และข้อสงวนการรับประกัน

NamLauncher เป็นรุ่นเสถียรแบบ community build ที่ยังไม่มีลายเซ็นโค้ดและอาจมี bug เท่าที่กฎหมายอนุญาต ผลิตภัณฑ์ให้ตามสภาพจริงโดยไม่มีการรับประกัน แต่สิทธิ์บังคับของผู้บริโภคยังคงมีผล

14. ข้อจำกัดความรับผิด

เท่าที่กฎหมายอนุญาต ผู้พัฒนาไม่รับผิดชอบบริการภายนอก คอนเทนต์อันตราย การลงโทษบัญชี ข้อมูลสูญหาย หรือความเสียหายทางอ้อม โดยไม่ยกเว้นความรับผิดหรือสิทธิ์ที่กฎหมายห้ามยกเว้น

15. การเปลี่ยนแปลง กฎหมาย การแยกข้อกำหนด และการติดต่อ

การเปลี่ยนสาระสำคัญจะเปลี่ยน version และขอให้ยอมรับใหม่ กฎหมายบังคับยังมีผลเหนือกว่า หากข้อหนึ่งใช้ไม่ได้ ข้ออื่นยังคงมีผล ติดต่อ nattapat2871.me สำหรับการขออนุญาต responsible disclosure ความเป็นส่วนตัว หรือการสนับสนุน

ประกาศความเป็นส่วนตัว

1. ขอบเขต ผู้ดูแล และการเก็บข้อมูลเท่าที่จำเป็น

ประกาศนี้ครอบคลุมซอฟต์แวร์และบริการ NamLauncher ที่ดูแลโดย nattapat2871 ระบบมุ่งเก็บเฉพาะข้อมูลที่จำเป็นต่อการทำงาน ความปลอดภัย การวัดผล และการสนับสนุน โดยไม่ขายข้อมูลส่วนบุคคลหรือใช้เพื่อโฆษณาแบบเจาะจง โปรดอย่าใส่ความลับในชื่อโปรไฟล์ ชื่อ instance ข้อความ support หรือ log ที่เลือกส่ง

2. ข้อมูลในเครื่องและการยืนยันตัวตน Microsoft

การตั้งค่า รหัสติดตั้งแบบสุ่ม สรุปบัญชี ข้อมูลยืนยันตัวตน instance คอนเทนต์ Java cache skin และ log จะเก็บในโฟลเดอร์ข้อมูล ข้อมูลยืนยันตัวตนเข้ารหัสด้วย secure storage เมื่อระบบรองรับ หากไม่รองรับอาจ fallback ไปเก็บในเครื่องโดยไม่มีการเข้ารหัสระดับระบบปฏิบัติการ ระหว่างเปิดหน้า LAN ระบบจะรับฟังประกาศ Minecraft ในเครือข่ายภายในแบบ passive และเก็บ private address คำอธิบายเซิร์ฟเวอร์ และพอร์ตชั่วคราวไว้ในหน่วยความจำเท่านั้น โดยไม่ส่งไปบริการ NamLauncher หรือบันทึกเป็นประวัติ เว็บไซต์ NamLauncher ไม่ขอรหัสผ่าน Microsoft

3. Heartbeat จำนวนออนไลน์แบบไม่ระบุตัวตนที่จำเป็น

ระหว่างที่ process ของ NamLauncher ทำงาน heartbeat สำหรับจำนวนออนไลน์เป็นฟังก์ชันที่จำเป็นและปิดไม่ได้ โดยจะยังส่งต่อเมื่อย่อลันเชอร์หรือซ่อนในถาดระบบ และหยุดหลังออกจากโปรแกรมโดยสมบูรณ์ Discord IPC เป็นการตั้งค่าแยกและเมื่อเปิดจะทำงานต่อระหว่างซ่อนหน้าต่าง ลันเชอร์ส่งรหัสติดตั้งแบบสุ่ม version, platform และสถานะเกม เซิร์ฟเวอร์เก็บ hash ที่ใส่ pepper กับเวลาและ metadata แล้วลบข้อมูลที่เก่ากว่า 7 วัน โดยไม่ตั้งใจส่ง Microsoft token แชต ที่อยู่เซิร์ฟเวอร์ หรือรายการไฟล์

4. สถิติ session การเล่นเกมที่จำเป็น

สถิติ session เป็นฟังก์ชันที่จำเป็นและปิดไม่ได้ระหว่างเล่นเกม ลันเชอร์ส่งชื่อโปรไฟล์ ประเภทบัญชี version, loader และ session start, heartbeat, session end เพื่อคำนวณเวลาเล่นจริงจากเวลาที่เซิร์ฟเวอร์รับ เมื่อเกมรายงานว่ากำลังเชื่อมต่อเซิร์ฟเวอร์ ลันเชอร์จะส่งที่อยู่และพอร์ตแบบ normalized เพิ่ม เพื่อให้แดชบอร์ดเจ้าของจัดอันดับจาก endpoint จริงแทนชื่อเซิร์ฟเวอร์ที่ผู้เล่นตั้งเอง โดยที่อยู่ private หรือ local จะเก็บเพื่อสถิตินี้ในระบบที่จำกัดสิทธิ์เท่านั้น รหัสติดตั้งเก็บเป็น hash เท่านั้น session ที่ขาด heartbeat จะปิด ณ ครั้งล่าสุดและค่าเริ่มต้นลบหลัง 365 วัน โดยไม่ส่ง token รหัสผ่าน แชต log เกม world หรือรายการไฟล์

4A. การรายงานสัญญาณมอดของอินสแตนซ์ที่เปิดแบบจำเป็น

ทุกครั้งที่เริ่มเกม ระบบจะตรวจตามนโยบายโดยปิดไม่ได้ และตรวจเฉพาะ metadata ของไฟล์ JAR ในโฟลเดอร์ mods ของอินสแตนซ์ที่กำลังเปิด แล้วส่งเฉพาะสัญญาณที่ตรงพร้อมชื่อโปรไฟล์ ประเภทบัญชี เวอร์ชัน Minecraft และ loader โดยไม่อัปโหลดไฟล์ พาธ token แชต ที่อยู่เซิร์ฟเวอร์ log เกม หรือ world รายงานลบหลัง 90 วันโดยค่าเริ่มต้น ผลที่พบเป็นเพียงสัญญาณที่อาจผิดพลาดหรือเป็นการใช้งานที่ชอบด้วยกฎหมาย ไม่ใช่หลักฐานยืนยันการโกง และความล้มเหลวของการตรวจหรือส่งไม่บล็อกการเปิดเกมเพียงเพราะเหตุนี้

4B. ไอคอนลันเชอร์ข้ามผู้เล่นแบบเลือกได้

เมื่อเปิดไอคอนในเกม ทั้งบัญชี Microsoft และ Offline จะเผยแพร่สถานะ UUID แบบ hash อายุสั้น เพื่อให้ผู้ใช้ NamLauncher เห็นไอคอนกันบนชื่อเหนือหัว Tab List และข้อความแชตผู้เล่นมาตรฐาน สำหรับลันเชอร์ปัจจุบันที่ระบุอย่างชัดเจนว่าเปิดไอคอนใน heartbeat ของ session การเล่นที่จำเป็น ระบบอาจสร้าง UUID มาตรฐานแบบ Java OfflinePlayer จากชื่อโปรไฟล์ที่ผ่านการตรวจรูปแบบแล้วเพื่อเทียบเฉพาะ UUID ที่ client ผู้ขอส่งมา สำหรับลันเชอร์รุ่นเก่าที่ไม่ส่งค่าการตั้งค่า ระบบจะสร้าง alias นี้เฉพาะเมื่อการติดตั้งเดียวกันยังเผยแพร่สถานะไอคอนโดยตรงซึ่งไม่หมดอายุ ทางสำรองหยุดเมื่อ session หรือสถานะโดยตรงจบหรือหมดอายุ ระบบจะไม่ถือว่าค่าที่ลันเชอร์รุ่นเก่าไม่ได้ส่งมาเพียงอย่างเดียวเป็นการเปิด และเคารพการปิดไอคอนที่ client ระบุไว้ ไอคอนเป็นเพียงเครื่องหมายตกแต่ง ไม่ได้พิสูจน์เจ้าของบัญชีหรือตัวตน และปิดได้แยกจากข้อมูลบริการที่จำเป็น

5. การเข้าชมเว็บไซต์ การดาวน์โหลด และ server log

เว็บไซต์เก็บภาษา theme และ timestamp ป้องกันนับ view ซ้ำใน browser local storage และใช้ visitor hash เพื่อป้องกันนับซ้ำโดยลบหลัง 90 วัน Server log อาจมี network address, user agent, path, status และเวลาเพื่อความเสถียรและป้องกันการใช้งานผิด โดยจำกัดผู้เข้าถึงและเก็บเท่าที่จำเป็น ยอดรวมที่ไม่ผูกกับ visitor hash อาจเก็บต่อ

6. บันทึกการทำงานและการติดตั้งคอนเทนต์

บริการและการติดตั้งผ่าน Modrinth หรือ CurseForge อาจบันทึก action ชื่อโปรไฟล์หรือ client hash แบบย่อ ประเภทบัญชี รหัสหรือชื่อคอนเทนต์ ผลลัพธ์ ระยะเวลา รายละเอียดที่จำกัดขนาด และ network/client hash ค่าเริ่มต้นลบหลัง 30 วันและตั้งใจไม่เก็บ password, token, chat หรือที่อยู่เซิร์ฟเวอร์ การบันทึกนี้แยกจาก stream heartbeat ออนไลน์ที่จำเป็น

7. ผู้ให้บริการบุคคลที่สามและข้อมูลเครือข่าย

การลงชื่อเข้าใช้ ค้นหา รูปภาพ และดาวน์โหลดอาจติดต่อ Mojang, Microsoft, Modrinth, CurseForge, ผู้พัฒนา loader, Java provider, CDN, GitHub หรือบริการ NamLauncher สำหรับ Discord launch presence ข้อมูลอ้างอิงรูปที่ส่งให้ Discord อาจระบุ Minecraft texture สาธารณะที่ตรวจสอบแล้วไปยัง mc-heads.net ผู้ให้บริการที่อุปกรณ์ติดต่อโดยตรงได้รับข้อมูลเครือข่าย และอาจได้รับรหัสบัญชี คำค้น คอนเทนต์ texture โปรไฟล์ หรือไฟล์ที่จำเป็นต่อคำขอตามข้อกำหนดของตน

8. กิจกรรม Discord

Discord IPC เปิดเป็นค่าเริ่มต้นสำหรับโปรไฟล์ใหม่และปิดได้ใน Settings ระหว่างที่เปิดและ process ของ NamLauncher ยังทำงานอยู่ รวมถึงตอนย่อหรือซ่อนหน้าต่างใน tray ระบบอาจส่งสถานะ ชื่อ instance ชื่อโปรไฟล์ ระยะเวลา และรูปอ้างอิงไป Discord desktop สำหรับ launch presence ระบบอาจใส่ Minecraft texture ID สาธารณะที่ตรวจสอบแล้วใน URL ภาพหัวของ mc-heads.net ที่ส่งให้ Discord ส่วน caller รุ่นเก่าอาจใช้ UUID หรือชื่อโปรไฟล์ หากยืนยันไม่ได้ว่า texture ID ตรงกับไฟล์สกินที่เลือก ระบบจะไม่ส่งภาพผู้เล่นขนาดเล็ก แทนการเสี่ยงแสดงหัวผิด และจะไม่ส่งผ่าน custom IPC เมื่อปิดการตั้งค่าหรือออกจากโปรแกรมโดยสมบูรณ์

8A. การเชื่อมบัญชี Discord แบบเลือกได้

การเชื่อมบัญชีใช้ Discord OAuth พร้อมสิทธิ์ identify และ guilds.join โดยเซิร์ฟเวอร์ใช้ token ชั่วคราวเพื่ออ่านโปรไฟล์และขอให้บอทเพิ่มบัญชีเข้า Discord server ที่ผู้ดูแลกำหนด ก่อนพยายาม revoke token ทันที ลันเชอร์ไม่เก็บ Discord password หรือ token ที่ใช้ซ้ำได้ หากเพิ่มสมาชิกอัตโนมัติไม่ได้ การล็อกอินยังสำเร็จและผู้ใช้เข้าร่วมเองผ่าน /discord ได้
